## Meloncillo

|                  |                                                                                     |
| ---------------- | ----------------------------------------------------------------------------------- |
| **Author(s)**    | Hanns Holger Rutz (SourceForge: `sciss`)                                            |
| **License**      | GPL-2.0                                                                             |
| **Platform**     | Cross-platform (Java Swing)                                                         |
| **Original URL** | [sciss.de/meloncillo](https://www.sciss.de/meloncillo/)                             |
| **SourceForge**  | [sourceforge.net/projects/meloncillo](https://sourceforge.net/projects/meloncillo/) |
| **Archive file** | `Meloncillo-0.75unstable080717.zip`                                                 |

> Meloncillo is a software for composing spatialisations. It does not imply a particular model of spatialisation by itself, but exposes a programmable interface to implement different models. The idea is to provide two types of objects in a graphical interface: 'Receivers' are static areas associated with intensities, very much like heat maps, and 'transmitters' are dynamically moving point-like objects. Their trajectories can be recorded in real time or edited offline on a timeline view. Algorithms included with the distribution are Vector-Based-Amplitude-Panning (VBAP), binaural convolution spatialisation (using the HRTF library from the IRCAM LISTEN project), and Ambisonics (using the IRCAM spat~ object). Originally developed as a M.A. project at the Electronic Studio of the TU Berlin.

![Meloncillo screenshot](https://www.sciss.de/meloncillo/images/screenshot.jpg)

## Amsterdam Catalogue of Csound Computer Instruments (ACCCI)

|                  |                                                                                                           |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| **Author(s)**    | John-Philippe Gather (Department of Music, University at Buffalo, SUNY)                                   |
| **License**      | Unknown                                                                                                   |
| **Platform**     | Cross-platform (Csound scores and orchestras)                                                             |
| **Original URL** | [Wayback Machine](https://web.archive.org/web/20141204175509/http://www.codemist.co.uk/AmsterdamCatalog/) |
| **Archive file** | —                                                                                                         |

> The ACCCI (Amsterdam Catalogue of Csound Computer Instruments) includes approximately 100 documented SWSS instruments, amongst which all of Risset's 25 Bell Lab Catalogue instruments and ca. 75 other instruments focussing on various aspects of Software Sound Synthesis (SWSS). All instruments have been programmed adopting one style, with strong emphasis on documentation and transparency. The corpus of instruments is systematically subdivided into a hierarchy of main groups and subgroups according to synthesis technique or topic. All programs are ready to run with the SWSS package Csound. Discussions and flowcharts are included in Encapsulated Postscript format (.eps files).
